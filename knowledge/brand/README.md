# Brand Knowledge Base

This directory contains brand guidelines, voice standards, and messaging frameworks for the Ren (Brand) assistant.

## Contents

### Brand Identity
- Brand values and mission
- Brand personality
- Voice and tone guidelines
- Visual identity standards

### Messaging
- Key messages
- Value propositions
- Taglines and slogans
- Positioning statements

### Content Standards
- Writing style guide
- Grammar and usage
- Formatting conventions
- Content templates

### Campaign Materials
- Campaign briefs
- Content calendars
- Asset libraries
- Performance benchmarks

## Using This Knowledge

The Ren (Brand) assistant references this directory to:
- Create on-brand content
- Maintain voice consistency
- Generate marketing materials
- Ensure brand alignment

## Customization for Clients

When deploying for a client:
1. Gather brand guidelines
2. Document voice and tone
3. Create messaging framework
4. Add to client-specific directory
